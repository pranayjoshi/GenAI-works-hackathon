Why it is an agent, not a pipeline
Uses tools
Queries its own runSQL against the event log it just wrote, plus Census and Pew through Zetaris.
Critiques itself
Checks, then revisesA code critic checks every number against its query, a model critic reviews the report, an honesty check guards every rewrite.
Asks permission
Owner approves spendFree, reversible steps proceed. Anything that spends money or publishes waits for a yes, and is created paused.
